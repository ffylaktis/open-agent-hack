# Prompts

Drop Meterless Engine prompt files here (from https://meterless.ai/engines.html).

Workflow:
1. **IDEATE** → map an engine onto your product idea.
2. **IMPLEMENT** → paste the engine's implementation prompt into Cursor's Agent
   chat with this project open; have it wire the engine into a real feature and
   run the conformance test.
3. **COMBINE / HARDEN** → add more engines, tests, guardrails.

You must integrate **at least one** engine into working code (H-Mem,
Markovian, World Model, or Scout Intent) — mentioning it is not enough.
